Partikelbasierte Fluidsimulation für interaktive Anwendungen

Leo Wandersleb · Diplomarbeit, TU München · eingereicht am 17. Januar 2005

A real-time SPH fluid solver whose neighbour search needs no grid: particles carry an implicit cell ID and are kept sorted by it, in four staggered lists, so memory scales with the particle count and not with the size of the simulated domain.
